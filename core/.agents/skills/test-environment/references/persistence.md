# 判断实验资产是否值得持久化

仅在能显著降低后续重建或误判成本时沉淀最小资产，优先归入所属项目的正式测试。

- **值得保留**：多步骤且预计复用的 `up`/`verify`/`down` 脚本、不显然的版本/兼容限制说明、复现必需的最小 fixture 与断言、可重建镜像配方。
- **无须保留**：常规标准命令、未验证猜测、整份 help、原始日志或临时凭据。
- 工作台级可复用场景放 `one-off-scripts/test-environments/<业务>/<场景>/`，同步 `one-off-scripts/README.md`，所有环境参数通过变量注入，不硬编码个人绝对路径。
